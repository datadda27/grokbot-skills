# grokbot-skills

Live skills for public Grok Bot templates. Each template's bot downloads its skill from here before every run, so fixes reach every user automatically.

## Bots

| Bot | What it does | Setup page | Template |
|---|---|---|---|
| CFB Recruiting & Portal Tracker | Follows one college football team's recruiting and transfer portal. Read only. | [portal-tracker/README.md](portal-tracker/README.md) | https://x.ai/bot/-FD_nk_KoOHBDShy2T4O7 |
| Prepper | Gets one household ready to stay home for two weeks, with calm, sourced steps. Never buys and never messages anyone but you. | [family-prepper/README.md](family-prepper/README.md) | https://x.ai/bot/-XeyX8_sUb_Ca0a6vqDYY |

Each setup page lists the bot's job, hard rules, workflow, skills, routines, integrations, and safety boundaries.
